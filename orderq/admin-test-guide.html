ORDER Q 관리자 직접 테스트 안내

이 화면은 실제 고객·판매·재고·ERP와 분리된 테스트 전용 환경입니다.

  1. 테스트 시작을 누르고 TEST 주문의 상품·주문수량 2개·출고 전 재고 10개를 확인합니다.
  2. 주문 확인 완료 후 출고 준비를 누릅니다. 재고 2개가 출고 준비 수량으로 잡히지만 재고는 아직 줄지 않습니다.
  3. 실제 출고수량에 2를 입력하고 실제 수량 저장을 누릅니다.
  4. 출고 확정을 누릅니다.
  5. 결과 화면에서 판매 기록 생성, 재고 10→8, 주문 완료 2/2, 오류 없음과 재시도 중복 0건을 확인합니다.
입력할 값실제 출고수량 2
기대 결과판매 2개 · 재고 차감 -2 · 주문 처리 2/2 · 오류 없음
다시 시작결과 화면의 ‘다시 시작’을 누릅니다. 확정된 테스트는 원자료를 지우지 않고 반대 기록으로 안전하게 되돌립니다.

주의: TEST 배지가 없는 화면에서는 이 안내의 테스트를 실행하지 마십시오.
