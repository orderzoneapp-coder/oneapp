# ORDER Q 수기 주문 상품 마스터 검색 명세

- 버전: vNext 0.4.2
- 우선순위: 수기 주문입력 P0
- 원칙: 공통 마스터는 읽기 전용으로 사용하고 주문 거래값과 분리한다.

## 목적

주문 행마다 품목코드·품목명·제2품명/약칭·검색창정보·규격으로 공통 상품 마스터를 즉시 검색한다. 관리자가 후보를 선택하면 주문 당시의 품목코드·품목명·규격·업무단위와 실제 `productId`를 저장한다. 수량·원단위·단가·메모는 이번 주문의 거래값으로 별도 입력한다.

## 동작

1. 품목코드 또는 품목명에 한 글자 이상 입력하면 최대 8개 후보를 표시한다.
2. 후보는 품목코드, 품목명, 규격, 업무단위, 제2품명/검색정보와 출처를 표시한다.
3. 마우스 선택 또는 위·아래·Enter로 확정하면 기본정보를 자동입력하고 수량 칸으로 이동한다.
4. 선택 뒤 품목코드나 품목명을 바꾸면 마스터 연결을 해제한다.
5. 후보가 없어도 직접입력을 허용하고 `MATCH_FAILED`로 저장한다.
6. 실제 마스터 후보를 선택한 행만 `MATCHED`로 저장한다. 단순히 코드와 품명을 입력한 행은 매칭완료로 간주하지 않는다.

## 데이터 원본과 저장

- 검색 우선순위: 같은 출처의 `MerchOpsDB/master_products` 공통 마스터 → ORDER Q 이력 상품.
- 공통 마스터와 ORDER Q 이력의 품목코드가 같으면 공통 마스터를 우선한다.
- 주문 품목에는 `productId`, 입력 원문, 주문 당시 품목코드·품목명·규격·업무단위, 수량·단가·메모, `matchStatus`, `matchSource`를 저장한다.
- 공통 마스터 원본은 ORDER Q가 수정하거나 복제 저장하지 않는다.

## 이번 안정화에 포함한 P0

- 주문·판매 양쪽 상품코드가 서로 다르면 품명이 같아도 출고 연결을 금지한다.
- SmartParser의 부분 변경·취소 메시지는 주문 전체를 자동 교체·취소하지 않고 수기 검수 대기로 저장한다.
- 음수 판매(반품·취소 역분개)는 파서사전 학습 근거에서 제외한다.

## 제외 범위

거래처별 단가 자동적용, 신규 공통 마스터 등록, 즐겨찾기, 변경 메시지의 행 단위 병합, 취소 범위 추론, 이력수집기·공통 마스터 저장구조 개편은 다음 단계로 넘긴다.
