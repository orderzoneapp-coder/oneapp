# 스마트입력 양식 검증 모드·전표 초기화 UI 작업 기록

## 양식 검증 모드

- 신규 양식 저장과 기존 양식 변경 저장이 같은 검증 모드를 사용한다.
- 검증 실패 시 오류 개수와 현재 순서를 표시하고 첫 오류 열을 자동으로 연다.
- 오류 열의 헤더와 매핑 상태를 강조하고 가로 화면 밖이거나 숨긴 열이면 자동으로 노출·이동한다.
- 중복 매핑은 양쪽 원본 열을 함께 강조하고 작업자가 사용할 열을 결정하도록 유지한다.
- 삭제되거나 존재하지 않는 대상은 사유를 표시하고 매핑 창에서 바로 비매핑 처리할 수 있다.
- 한 오류를 수정하면 즉시 재검증하여 다음 오류로 이동하며, 모두 해결되면 기존 저장 동작을 자동 재개한다.
- 이전 오류·다음 오류 수동 탐색을 제공한다.

## 전표 초기화 UI

- `전표 초기화`를 위험 작업으로 식별되는 강조색 버튼으로 변경했다.
- 버튼 오른쪽의 인라인 검증 문구는 화면에서 제거하고 스크린리더 상태 알림으로 유지했다.
- 가운데 작업영역 툴바가 가로로 좁아지거나 스크롤되어도 버튼을 우측 끝에 고정한다.
