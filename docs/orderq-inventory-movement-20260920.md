# ORDER Q 재고변동표

사용자 요청: 전일재고현황·재고변동표를 모두 재고로 읽고 판매·구매 내역을 반영하며, 재고실사와 수정을 엑셀 형태의 표에서 수행한다. 재고 원본에 없는 거래 품목의 기초재고는 사용자가 0으로 계산하도록 확정했다.

기준: `origin/main`의 `f7c5d2bebcbcb8e4bd71d6813f7989091914b1a3`. 전용 브랜치에서 구현·직접 검증하며, 원본 Excel, 다른 앱의 저장소와 공식 전표 원장은 변경하지 않는다.

- 기존 창고별 수량 양식을 유지하며 단일 재고와 재고변동 양식을 추가한다.
- 재고변동표는 기초재고 + 입고 − 출고로 계산한다. 업로드한 구매·판매 파일은 해당 입고·출고 자료를 대체하며 기존 집계를 다시 더하지 않는다.
- 재고실사의 공란과 0을 구분한다. 공란이면 계산잔량, 실사값이 있으면 실사값이 확정재고다. 실사차이는 실사값 − 계산잔량이다.
- 입력 수정은 원본과 분리한 로컬 작업본으로 보존한다. 기존 저장·복구 경로와 Excel 출력에 포함한다.
- 신규 재고변동표의 기초재고 0 정책은 기존 주문 배분의 미매칭 재고 정책을 변경하지 않는다.
- 문자열 품목코드, 소수, 음수와 반품을 보존한다. 합계와 출력시각 행은 데이터에서 제외한다.
- 무재고 판매와 초과 판매는 음수 잔량으로 표시하며 차단하거나 0으로 보정하지 않는다. BOX(대소문자 무관)·박스 외 단위는 빨간 글씨, 음수 숫자 셀은 노란색 바탕으로 구분한다.

검증 기준: 두 재고 형식 각각의 파싱, 구매·판매의 품목별 집계, 재업로드 중복 방지, 재고실사 0/공란, 수정·붙여넣기·복구·출력, 기존 창고재고와 주문 배분 회귀. 실제 파일의 집계값은 원본에서 독립 계산해 대조하며 원본 파일은 저장소에 포함하지 않는다. 기존 재고변동표와 새 판매현황의 출고량이 다르면 제공 판매현황을 우선하고 원본과의 차이를 표시한다.

복구: 코드 변경은 PR revert로 복구한다. 기존 작업본과 원본은 삭제하거나 마이그레이션하지 않는다. 새 실사·수정 필드는 기존 작업공간에 선택 필드로 보관한다.
