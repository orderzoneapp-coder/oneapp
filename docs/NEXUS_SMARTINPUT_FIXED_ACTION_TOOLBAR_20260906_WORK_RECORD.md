# 스마트입력 기본 작업바 위치 고정 작업 기록

## 변경

- 기본 작업바에는 상시 사용하는 검색·보기 전환·행 편집·전표 초기화 기능만 유지했다.
- 양식 상태, 양식 저장/변경, 검증 탐색은 기본 작업바 아래의 단일 하위 작업바로 이동했다.
- 행 수·매핑·추천·미결정·비매핑 통계는 기본 작업바에서 제거하고 접근성 상태 정보로만 유지했다.
- 원본형/입력형 설명 문구를 화면에서 제거했다.
- 기본 버튼 묶음만 독립적으로 가로 스크롤되며 `전표 초기화`는 별도 고정 슬롯에 항상 노출되도록 구조를 분리했다.
- 하위 작업바가 열리고 닫혀도 기본 작업바 버튼 순서와 위치가 변경되지 않는다.

## 검증

- 브라우저에서 기본 작업영역 우측 경계와 `전표 초기화` 버튼 우측 경계가 일치하는 것을 확인했다.
- 입력 양식 브라우저 E2E, 10,000행 매핑, 작업영역 회귀 테스트를 통과했다.

## 배포 버전

- CSS `0.9.10`
- JavaScript `0.11.35`
