# SmartInput ERP 견적서현황 갱신·F8 Excel 사용가이드

## 1. ERP 견적서현황 불러오기

1. SmartInput에서 `견적서` 탭을 연다.
2. ERP에서 내려받은 `견적서현황.xlsx`를 원본입력 영역에 끌어놓거나 Excel 파일로 선택한다.
3. 원본입력뷰 상단에서 선택 결과를 확인한다.
   - 시트: `견적서현황내역`
   - 제공 파일 기준: 거래처 10곳, 품목 277개
4. 처음 보는 양식이면 23개 열을 `매핑` 또는 `비매핑`으로 모두 확정하고 입력 양식을 저장한다. 이미 저장된 동일 양식이면 저장된 매핑이 자동 적용된다.

`Sheet1`은 창고 02의 부분집합이므로 함께 합치지 않는다. SmartInput은 정확한 23열 ERP 형식의 `견적서현황내역` 한 시트만 우선한다.

## 2. 거래처별 기존 견적서 갱신

1. 매핑 결과와 품목을 확인한 뒤 화면 하단의 저장 작업을 실행한다.
2. `거래처별 견적서 업데이트` 창에서 각 거래처의 `처리 대상`을 지정한다.

| 처리 대상 | 동작 |
|---|---|
| 기존 견적서 | 선택한 SmartInput 개별 견적서를 해당 거래처 자료로 교체 갱신 |
| 새 견적서 명시 등록 | 입력한 견적서명으로 새 개별 견적서 생성 |
| 이번 작업 제외 | 해당 거래처를 이번 저장에서 제외 |

3. 저장할 행의 `선택`을 확인한다.
4. 하단의 `정상 전표 업데이트`를 누른다.
5. `저장 완료 / 확인 필요 / 변경 없음` 집계를 확인한다.

확인 필요인 거래처는 일부 품목만 저장하지 않는다. 해당 거래처 전표 전체를 보류하고, 다른 정상 거래처는 독립적으로 저장한다. ERP 파일에 없는 기존 견적서는 변경하지 않는다.

## 3. 기존 견적서가 목록에 보이지 않을 때

오른쪽 `개별 견적서` 목록과 갱신 창은 SmartInput에 저장된 개별 견적서를 사용한다. ERP 서버에만 있는 견적서는 자동 조회하지 않는다. `연동견적서`는 별도 목록이며 거래처별 갱신 대상에서 제외된다.

확인 순서:

1. 오른쪽 목록이 `개별 견적서`인지 확인한다.
2. 이 F8 배포 범위의 견적서와 입력 양식은 현재 브라우저의 로컬 저장소에 있다. 다른 브라우저·PC의 자료는 아직 자동으로 나타나지 않는다.
3. ERP에만 있고 SmartInput에 한 번도 저장하지 않은 견적서는 갱신 창에서 `새 견적서 명시 등록`으로 최초 생성한다.

다른 PC 연동은 별도 클라우드 동기화 배포와 서버 활성화가 완료된 뒤 사용할 수 있다. 서버 활성화 전에는 동기화가 되는 것으로 간주하면 안 된다.

## 4. MerchOps F8 형식으로 출력

1. 오른쪽에서 출력할 개별 견적서를 연다. 여러 견적서를 출력하려면 다중 선택한다.
2. `F8 EXCEL` 버튼을 누르거나 키보드 `F8`을 누른다.
3. 다운로드된 `통합업로드용_QuickF8_YYYY-MM-DD.xlsx`를 확인한다.

| 시트 | 생성 조건 | 형식 |
|---|---|---|
| 쇼핑몰업로드 | 항상 | MerchOps F8 22열 |
| ERP업데이트 | 항상 | MerchOps F8 16열 |
| 확인요청 | 도매가 확인 경고가 있을 때만 | 확인 대상과 사유 |

현재 화면에서 저장하지 않은 명시적 수정도 출력에 반영된다. 원본 공란과 숫자 0은 구분해서 보존하며, 품목코드의 선행 0과 끝의 `.0`도 임의로 제거하지 않는다.

## 5. 출력이 차단되는 경우

다음 상황에서는 잘못된 대표값을 임의 선택하지 않고 파일 생성을 중단한다.

- 출력 품목코드 중복
- 소분상품의 공식 상품정보 누락
- 한 소분코드에 서로 다른 원물이 연결된 경우
- 연동견적 원본 누락 또는 손상된 원본 행 연결
- 여러 원본 행에 연결된 편집값의 적용 대상을 결정할 수 없는 경우

제공된 ERP 파일은 거래처별 견적 안에서는 품목코드 중복이 없지만, 10개 거래처 전체를 한 번에 합치면 다음 네 코드가 거래처 사이에서 중복된다.

- `103044110`
- `104524112`
- `105522110`
- `105524122`

따라서 이 파일은 먼저 거래처별 견적서를 갱신한 뒤 개별 출력할 수 있다. 여러 거래처를 한 파일로 묶으려면 네 중복코드의 기준을 먼저 정리해야 한다.

## 6. 하단 버튼이 보이지 않을 때

갱신 창의 목록 본문만 스크롤되며 하단의 `닫기`와 `정상 전표 업데이트`는 화면 안에 고정된다. 이전 화면이 남아 있으면 강력 새로고침 후 다시 연다.

- Windows: `Ctrl + F5`
- macOS: `Command + Shift + R`
