## 남는 문제와 다음 순서

이 기준은 완전 무결한 계산 안정판이라는 뜻이 아니다. 기존 재검증의
재고 수기 수정 후 배분 재계산(F05), 서로 다른 단위 합계(F06/F08),
구매만 있는 품목의 수불 누락(F07)은 롤백으로 해결되었다고 판정하지 않는다.
동적 창고 매핑/시트명 변형(F02/F03)도 기본 정상 파일 확인과 별개다.

1. 복원한 기본 화면으로 실제 사용 흐름을 확인한다.
2. 사용 중 재현되는 파서·수량·금액·수불 오류를 건별 수정하고 화면/저장/Excel을 비교한다.
3. 이후 확정된 기획을 기본 흐름 위에 작은 변경 단위로 재도입한다.

3영역·주문묶음·API 연결 확대를 선행조건으로 다시 넣지 않는다.
추가 소스 복구가 필요하면 이 PR의 화면·엔진·출력·검사 변경 묶음을 반대 적용하며,
데이터를 Git 소스와 함께 되감거나 삭제하지 않는다.
