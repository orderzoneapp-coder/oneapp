# 스마트입력 워크벤치 레이아웃 롤백 작업 기록

- 작업일: 2026-09-11
- 기준: 운영 `main`의 NEXUS 6개 앱 작업영역 재구축 배포본
- 사용자 지시: 스마트입력 레이아웃 롤백
- 롤백 범위: `smartinput/index.html`의 공통 좌·중·우 재구축 마크업과 공통 폭조절 CSS/JS 연결, 공통 모듈의 `smart-input` allowlist 및 전용 보조 스타일
- 유지 범위: 7개 글로벌헤더, 스마트입력 업무 로직과 데이터·저장·변경이력·오류복구 계약, 기존 원본입력뷰·입력표·우측 견적서 목록과 자체 폭조절 기능
- 보호 범위: 상품관리·거래처관리·스마트파서·MerchOps·DataOps 재구축 레이아웃과 출고관리 롤백 상태
- 검증 기준: 스마트입력 재구축 직전 승인 HTML 기준 해시, 전용 정적 계약, 전체 브라우저 E2E, 독립 복구·저장 회귀, 공통 5개 앱 레이아웃 회귀, 저장소 전체 검증
- 배포 기준: 별도 커밋·PR로 `main` 병합 후 Pages 성공과 운영 URL의 공통 레이아웃 자산 미참조 및 기존 화면 구조를 확인한다.
