# 스마트입력 입력 양식 재매핑·보고서 분리 작업 기록

## 요청

- `0905전송.xlsx`처럼 거래처 후보 열이 여러 개인 구매 파일에서 잘못 지정한 필드 매핑을 다시 수정할 수 있어야 한다.
- 입력 양식 저장이 일부 미결정 열 때문에 막히지 않아야 한다.
- 저장된 양식마다 보고서 출력 열과 식별 정보가 달라야 한다.

## 변경

- 적용된 공식 양식에서도 각 원본 열의 매핑/비매핑을 직접 수정할 수 있게 했다.
- 변경한 매핑은 즉시 현재 작업 데이터에 다시 투영하고, `양식 변경 저장`으로 같은 양식의 다음 개정판을 저장한다.
- 새 양식 저장 시 사용자가 결정하지 않은 열은 자동으로 비매핑 처리해 제외한다. 중복 필드 등 실제 충돌은 계속 검증한다.
- 보고서 출력 열은 화면 공통 설정 대신 현재 적용 양식의 매핑 순서와 필드를 사용한다.
- 보고서 제목과 파일명에 적용 양식명을 포함해 양식별 출력물을 구분한다.
- 스마트입력 스크립트 배포 토큰을 `0.11.33`으로 갱신했다.

## 검증

- 입력 양식 브라우저 E2E에서 적용 양식 재매핑, 개정 2 저장, 보고서 열/파일명 반영을 확인했다.
- 10,000행 매핑 성능 및 입력 양식 단위 테스트를 통과했다.
- 설정 UX, 데스크톱 작업영역, 독립 복구 호환성 회귀 테스트를 통과했다.
- 원본 Excel 파일은 읽기 및 업로드 검증에만 사용하고 수정하지 않았다.
