# SmartInput 작업바 정렬·입력형 기본값 작업 기록

- 일자: 2026-09-07
- 범위: 스마트입력 기본 작업바와 테이블 표시 방식

## 반영 내용

- `입력 양식 저장`을 기본 작업바 좌측 고정 영역으로 이동했다.
- `입력목록 검색(F3)`을 `검색(F3)`으로 축약했다.
- 단가 일괄 적용 영역을 숫자 입력칸과 `단가 적용` 버튼으로 간소화했다.
- 우측 고정 행 작업을 `빈 행 추가 → 붙여넣기 취소 → 선택 삭제` 순서로 배치했다.
- `원본형`과 `입력형` 전환을 데이터 유무와 관계없이 항상 노출한다. 원본 데이터가 없을 때만 `원본형`을 비활성화한다.
- 새 엑셀 분석, 개별 저장 견적서 재진입, 화면 재진입의 기본 테이블을 `입력형`으로 통일했다.
- 우측 패널에서 `연동견적서`를 선택한 경우에는 원본 확인이 우선이므로 `원본형`으로 연다.
- 양식 검증 안내와 오류 열 강조 색상을 경고 계열의 낮은 톤으로 조정했다.
- 중간 화면 폭에서 우측 패널이 고정 작업 버튼을 가리지 않도록 작업바 여백을 보정했다.

## 캐시 버전

- CSS: `0.9.11`
- JavaScript: `0.11.37`

## 검증

- 테이블 표시 상태 단위 테스트
- 입력 양식 매핑 단위 테스트(10,000행)
- 입력 양식 브라우저 E2E
- 스마트입력 전체 브라우저 E2E
- 앱 헤더·환경설정·독립 복구 계약 테스트
- 1440px 밝은/어두운 테마 및 390px 모바일 화면 캡처
