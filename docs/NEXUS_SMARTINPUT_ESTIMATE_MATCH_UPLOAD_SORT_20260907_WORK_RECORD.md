- 거래처별 견적서 일괄 업데이트는 현재 파일의 선택 진행상태와 기존 견적서의 거래처 ID·코드·이름 정확 일치만 재사용한다.
- 사용자가 수동으로 확정한 원본 거래처와 대상 견적서의 관계는 다음 파일에 재사용되지 않는다.

- 성공한 거래처별 견적서 생성·업데이트 관계를 SmartInput 소유 `customerAliasMappings` 저장소에 확정 매칭으로 기록한다.
- 다음 파일에서는 원본 거래처 ID, 코드, 정규화 이름 순으로 유효한 확정 매칭을 찾아 대상 견적서를 자동 선택한다.
- 삭제되었거나 연동견적서인 대상 및 서로 충돌하는 매칭은 자동 적용하지 않는다.
- `견적서 업로드` 데이터행만 거래처명 → 품목코드 순으로 안정 정렬한다.
- `구매 업로드` 데이터행만 거래처명 → 코드 순으로 안정 정렬하여 거래처별 전표 행을 연속 배치한다.
- 쇼핑몰·ERP·판매입력 등 다른 시트의 기존 행 순서와 산출 규칙은 보존한다.
