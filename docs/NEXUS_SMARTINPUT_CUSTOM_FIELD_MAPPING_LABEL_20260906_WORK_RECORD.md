# SmartInput 사용자지정 매핑 표시 개선 작업기록

## 변경

- 사용자지정 항목은 전표 상단과 하단에서 각각 생성·배치할 수 있는 기존 저장 계약을 유지한다.
- 필드명 매핑창에서 사용자지정 항목명은 `(사용자)`로 구분하고 전체 경로는 `구매 > 사용자지정 > 하단 정보 > 상장가` 형식으로 표시한다.
- 바깥 작업테이블의 추천 상태에서는 `추천` 문구를 제거한다.
- 기본 항목은 `하단 정보 > 상장가`, 사용자지정 항목은 공간을 고려해 `하,상장가(i)` 형식으로 표시한다. 상단 사용자지정은 `상,항목명(i)` 형식을 사용한다.

## 검증

- 상단·하단 사용자지정 생성 브라우저 E2E 통과
- 입력 양식 매핑 브라우저 E2E 통과
- 설정 UX, 독립 복구, 보호 워크스페이스 및 Phase 6B 계약 통과
- SmartInput module cache token은 `0.11.32`이다.
