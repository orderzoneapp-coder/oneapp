# NEXUS 앱 공통 UI 계약

`NEXUS_APP_UI_V2`는 공통헤더 아래 앱에 하나의 고정 레이아웃을 제공한다. 별도 간격 전환이나 저장 설정은 두지 않는다.

## 공통 변수

| 변수 | 고정값 |
|---|---:|
| `--nexus-content-max-width` | 1440px |
| `--nexus-content-gutter` | 24px |
| `--nexus-app-header-height` | 56px |
| `--nexus-target-tab-height` | 42px |
| `--nexus-work-tools-height` | 50px |
| `--nexus-table-header-height` | 40px |
| `--nexus-table-row-height` | 48px |

NEXUS 공통헤더와 앱 작업헤더의 `.nexus-app-header-content`는 브라우저 전체 폭을 사용한다. 앱 본문 작업영역만 `.nexus-app-content`로 중앙 정렬하고 공통 최대 폭을 적용한다. 좁은 화면에서는 가용 폭을 모두 사용하고, 표는 카드로 변환하지 않고 가로 스크롤을 유지한다.

## 화면 모드

- 공통헤더의 `일반 / 다크` 선택을 단일 화면 모드로 사용한다.
- 앱은 `oneapp.nexus.v1.colorMode`를 별도 값으로 복사하지 않고 `data-nexus-theme`와 공통 디자인 토큰을 소비한다.
- 저장값이 없으면 `일반`을 적용하고, 기존 `system` 저장값은 `일반`으로 자동 전환한다. 운영체제 화면 모드는 읽지 않는다.
- `nexus-theme-init.js`가 첫 화면 전에 저장 모드를 적용하고, 공통헤더의 `nexus-theme-change`와 루트 속성 갱신이 실행 중 변경을 담당한다.
- Master 상품 조회와 상품 기초정보 관리는 동일한 배경·표면·테두리·문자 토큰을 사용한다.

## 기초등록 적용 상태

- 앱 작업헤더 한 줄 안에 `기초등록`, `상품`, `거래처`를 배치한다.
- 별도의 검은 `MASTER · 상품/거래처` 제목바를 사용하지 않는다.
- 앱 작업헤더는 본문 최대 폭과 독립된 전체 폭을 사용한다.
- 두 번째 도구 줄은 현재 부모와 `조회`/`일괄관리` 하위 경로를 항상 표시한다.
- 상품·거래처 조회는 기본 상태이며, 검색·건수·화면 작업은 오른쪽 작업 그룹에 둔다.
- 상품·거래처 작업영역과 내장 거래처 화면은 같은 중앙 기준 폭을 사용한다.
- 상품 조회, 상품 기초정보 관리, 내장 거래처 화면과 모달은 공통헤더 화면 모드를 즉시 반영한다.
- 내장 거래처 화면의 테마 메시지는 동일 출처의 `ONEAPP_NEXUS_THEME`만 수신한다.
- Master와 상품 등록은 고정 레이아웃 시범 적용 상태다.

## 적용 상태와 예외

| 앱 ID | 상태 | 적용 범위 | 예외·대체 UI | 재검토 조건 |
|---|---|---|---|---|
| `master-lookup` | 시범 적용 | 작업헤더, 대상 탭, 작업 도구, 표, 중앙 기준 폭 | 없음 | 운영 수용 기준 통과 시 |
| `item-manager` | 시범 적용 | 작업헤더, 대상 탭, 조회 도구, 편집표 | 없음 | 운영 수용 기준 통과 시 |
| `merchops` | 등록 예외 | 아직 미적용 | 기존 가격·행사 작업표와 F7/F8/F9 유지 | 기초등록 시범 적용 검증 후 |
| `dataops` | 등록 예외 | 아직 미적용 | 기존 자체 환경설정과 검증표 유지 | MerchOps 적용 검증 후 |
| `orderq` | 등록 예외 | 아직 미적용 | 기존 주문·구매·출고 작업대 유지 | DataOps 적용 검증 후 |
| `smart-parser` | 등록 예외 | 아직 미적용 | 기존 원본·파싱·마스터 검토 화면 유지 | ORDER Q 적용 검증 후 |

등록되지 않은 예외는 허용하지 않는다. 후속 앱 적용은 이 표와 코드 등록부를 함께 갱신하고 해당 앱 회귀검사를 통과해야 한다.
