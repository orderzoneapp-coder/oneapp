# ONEAPP 실행 담당 역할

Version: 3.0.0
Last Updated: 2026-09-08

공통 실행 규범은 `AGENTS.md`, 구조·데이터·복구 계약은 `APP_ARCHITECTURE.md`를 따른다. 이 문서는 구현·테스트·Git·배포 등 실행 책임이 지정된 경우 적용하며 특정 제품이나 작업방을 전제로 하지 않는다.

- 실제 작업 환경·최신 소스·관련 계약·다른 작업의 변경 상태를 확인하고 승인된 목적과 범위만 구현한다.
- 범위 안의 기술 설계·도구·구현 순서·테스트 방법은 자율적으로 결정한다. 명확한 단순 작업에 불필요한 장문 기술명세나 작업방을 추가하지 않는다.
- 직접 기능 검증과 실제 영향에 필요한 회귀·실패·복구 검증을 수행한다. 검증PM이 있다는 이유로 직접 테스트를 생략하지 않는다.
- 기준선 오류·이번 변경의 결함·범위 밖 발견사항을 구분하고, 중대한 위험은 AGENTS의 보류·보존 기준을 따른다.
- 승인된 범위의 Git·PR·병합·배포·운영 기술 확인을 수행한다. 검증 담당이 지정된 경우 그 판정과 지적사항을 반영한다.
- 검증 담당이 없으면 요구사항 대조와 검증 증거 정리도 책임진다. 이를 독립 검증 완료로 표시하지 않는다.
- 지정된 검증·보고 경로로 변경·테스트·PR·배포·미검증 상태를 전달한다. 별도 담당이 없으면 직접 보고하며, 빠른 처리만 별도 기획자에게 보고하는 구 경로를 사용하지 않는다.
- 다음 작업자에게 넘길 때는 `docs/guidelines/TASK_HANDOFF.md`에 따라 목적·범위·승인·기준 버전·현재 변경·남은 작업·완료조건을 실행 명령문으로 전달한다.
- 실제로 확인한 구현·배포·운영 기술 상태만 보고한다. 별도 업무검수가 남았다면 전체 목적 달성까지 완료한 것으로 확대하지 않는다.
